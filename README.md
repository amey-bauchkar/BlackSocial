# 🌟 Black Social Team Foundation (BSTF) — Official Redesign

A website redesign for **Black Social Team Foundation**, a non-profit public charitable trust dedicated to emergency medical care, slum children's education, street animal protection, and monthly hunger relief drives.

---

## 🎨 Design System & Aesthetic
* **Color Palette**: Warm Peach (`#FFF4E8`), Tangerine Orange (`#FF7B00`), Bubblegum Pink (`#FFAEC5`), Mint Green (`#90E0AA`), and Sunshine Yellow (`#FFDD67`).
* **Typography**: Paytone One (Display Titles), Plus Jakarta Sans (Body), Space Mono (Badges & Trust Numbers).
* **Architecture**: Fully modular 9-page website built with semantic HTML5, Vanilla CSS, and lightweight modern JavaScript.
* **Responsiveness**: 100% mobile-first optimized across all screen sizes (320px to 4K displays).

---

## 📂 Multi-Page Directory

1. [`index.html`](index.html): **Homepage** — Above-the-fold trust bar (80G, 12A, Verified Estimates), interactive arch photo slideshow, 2x2 metric stats ticker, 7 pillars summary, and urgent medical warriors preview.
2. [`missions.html`](missions.html): **Our 7 Missions** — Comprehensive breakdown of Old-Age Sanctuary, Animal Shelter, Slum Education, Free Healthcare OPDs, Monthly Meal Relief, Warmth Drives, and Women Empowerment.
3. [`warriors.html`](warriors.html): **Medical Warriors** — 6 emergency hospital cases with progress bars, verified estimates, and document lightbox popups.
4. [`scholars.html`](scholars.html): **Scholars Support** — Education sponsorship profiles, tuition fees breakdown, and child sponsorship options.
5. [`activities.html`](activities.html): **Activities & Drives** — 10 grassroots campaigns with interactive category filters (Meals, Education, Health, Animals, Social).
6. [`donate.html`](donate.html): **Donation Hub** — 50% 80G Tax Exemption benefit, instant preset amount selector, direct bank transfer card with one-click copy, and scan-and-pay UPI QR code.
7. [`team.html`](team.html): **Our Volunteers** — Core volunteers directory, executive trustees, and interactive volunteer application form.
8. [`documents.html`](documents.html): **Trust & Transparency Vault** — 80G, 12A, Trust Deed (L044214), PAN, and TAN certificate viewer.
9. [`contact.html`](contact.html): **Contact & Helplines** — 24/7 WhatsApp helpline, calling support, Mumbai base, and interactive contact form.

## 🚀 Local Development

To run locally:
```bash
# Clone the repository
git clone https://github.com/amey-bauchkar/BlackSocial.git

# Navigate into the project folder
cd BlackSocial

# Start a local static server
python -m http.server 8080
# or
npx serve .
```

Open `http://localhost:8080` in your browser.
